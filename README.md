# 食べ物・栄養チェック (Food & Nutrition Check)

写真をアップロードすると、AIが食べ物を判定し、おおよそのカロリー・栄養素(タンパク質・脂質・炭水化物)を表示するWebアプリです。

## セットアップ

```bash
npm install
npm run dev
```

## 使い方

1. アプリを開くと、Anthropic APIキーの入力を求められます。
   - APIキーはブラウザの `localStorage` にのみ保存され、外部には送信されません。
   - 画像解析リクエストは、ブラウザから直接 Anthropic API に送信されます。
2. 「写真を選ぶ」から食べ物の写真を選択(またはカメラで撮影)します。
3. 「栄養を判定する」を押すと、食べ物名・目安量・カロリー・栄養素・健康アドバイスが表示されます。

## 技術スタック

- React + TypeScript + Vite
- Anthropic API (Claude, マルチモーダル画像解析)

## 注意事項

表示される栄養情報はAIによる概算です。正確な栄養情報については、食品の成分表示等をご確認ください。
