# 健康カメラ (Health Camera)

毎日の食事をスマホのカメラで記録し、健康スコアで食生活を振り返るためのWebアプリです。

## 公開URL

https://toshinz777-source.github.io/food-health-camera/

`main` ブランチへのpushで GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) が自動的にビルド・デプロイします。

## セットアップ

```bash
npm install
npm run dev
```

## 使い方

1. ホーム画面の「食事を撮影」から、写真を撮る（またはアルバムから選ぶ）
2. AI自動判定が設定されていれば、食べ物の名前・内容（野菜・果物・タンパク質・炭水化物・脂質・甘い物・塩分・加工食品）が自動入力される（未設定、または判定に失敗した場合は手動で選択）
3. 内容を確認・修正し、食事の種類（朝食・昼食・夕食・間食）を選ぶ
4. 「保存する」で記録

記録は端末のブラウザ内（IndexedDB）に保存され、ページを閉じても消えません。

- **ホーム**: 今日の健康スコアと食事記録の一覧
- **カレンダー**: 過去の日付ごとの健康スコアを色分けで表示
- **週間**: 直近7日間の健康スコアの推移と週間平均

## 健康スコアについて

各食事は0〜100点で採点されます（野菜・果物・タンパク質はプラス、甘い物・塩分・加工食品・脂質はマイナス）。1日のスコアはその日の食事の平均です。極端な採点にならないよう、1回のお菓子程度では大きく点数が下がらないよう調整しています。

## AIによる自動判定(オプション)

写真から食べ物の名前・栄養カテゴリをClaude APIで自動判定できます。GitHub Pagesは静的ホスティングのためAPIキーをフロントエンドに置けないので、[Cloudflare Worker](worker/) がAPIキーをサーバー側で保持し、フロントエンドはそのWorkerに画像を送るだけにしています。セットアップ手順は [worker/README.md](worker/README.md) を参照してください。

未設定の場合や判定に失敗した場合は、これまで通り内容を手動で選択できます(常にフォールバック可能)。

## 技術スタック

- React + TypeScript + Vite（フロントエンド）
- Cloudflare Workers + Anthropic API（AI自動判定、オプション）
- IndexedDB（データ保存）

## 注意事項

このアプリは医療診断をするものではありません。食生活を振り返るための参考情報としてご利用ください。
